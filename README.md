# AI Chatbot Engineering

A hands-on learning journey focused on building AI-powered applications using Python, Large Language Models (LLMs), and modern AI engineering techniques.

This repository documents my progress as I explore chatbot development, LLM integration, conversational memory, Retrieval-Augmented Generation (RAG), and AI agents.

## Learning Objectives

- Build AI-powered applications using Python.
- Understand and integrate Large Language Models.
- Work with APIs and prompt engineering.
- Implement conversational memory.
- Explore embeddings and vector databases.
- Develop Retrieval-Augmented Generation (RAG) applications.
- Build AI agents and tool-calling systems.
- Learn to deploy and maintain AI applications.
